# Music & Mind — v3

Static website for musicandmind.in.

Files:
- index.html — website structure and content
- style.css — design and responsive layout

The site is intentionally built without a database, framework, or backend so it is easy to host and change later.

Before publishing:
1. Replace placeholder contact email if needed.
2. Review all wording, especially any references to wellbeing/therapy.
3. Add real social links if desired.
4. Choose a static host.
5. Connect musicandmind.in through GoDaddy DNS after the host provides the required records.

Do not delete GoDaddy email MX records when connecting the website.
